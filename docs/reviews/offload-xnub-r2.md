## Findings

### F1 (MEDIUM) the mirror precondition is evaluated by the wrong git/uid and runs commit code on the host
- tools/remote-job:177 runs `bash tools/xnu-src-mirror env ...` of the commit under test on the offload-host HOST, outside the container, with network, as the login user. The build later reads the mirror in the container as `--user 1000:1000 --userns=keep-id` with the image's git; "dubious ownership" is decided there. If the offload-host login uid is not 1000, or the image git differs, the precondition says OK and the 7-11 min build dies at stager 0019 exactly as before ([guess]: offload-host uid unknown; the repo never recorded `id -u` of offload-host). It also runs unsandboxed commit code on the host, while every other piece of the commit runs in the network-less container. And on failure only the `NOT mirrored` and RESULT lines are printed (:179 greps them), the `not servable ... dubious ownership` reason line of the real tool (stderr line before `NOT mirrored`) is dropped.
- Failing scenario: stager rsyncs the mirror as login user U (U != 1000); gate-pre passes the precondition, container uid 1000 cannot serve it, build rc 98 "XNU stack did not build" after the cold build.
- Fix: run the check in the same container: `mx=$("${xf[@]}" bash tools/xnu-src-mirror env --stack xnu/patches --dir $OFFLOAD_HOME/pixelios-artifacts/git-mirror 2>&1 >/dev/null)` (xf already has --rm, the name, mounts; run before the build, sequential so the name is free) and on failure print `$(tail -n 6 <<<"$mx")` instead of the two greps.

### F2 (MEDIUM) the stager cannot find an ownership/uid problem before the 7-11 min validation
- tools/offload-stage-xnub:53-55, :85-95. First real proof; if F1's mismatch exists, the validation only finds it at the end.
- Fix: in the first remote script (:53) add `[ "$(id -u)" = 1000 ] || { echo "stage: WARNING offload-host login uid is $(id -u), the container runs uid 1000 (--user 1000:1000 --userns=keep-id)"; }`; and in the validation script, before the build line, run `"${XF[@]}" bash tools/xnu-src-mirror env --stack xnu/patches --dir $OFFLOAD_HOME/pixelios-artifacts/git-mirror >/dev/null` and `exit 92` unless its stderr says `mirrored=N of N` (same check as F1, shared text would be better: put it in tools/xnub-line.sh as a function so both callers use it, AP-269 style drift guard).

### F3 (MEDIUM, conditional) running the stager from this branch alone makes `--validate` fail by design
- tools/offload-stage-xnub:42-49: missing `tools/xnu-src-mirror` is only a WARNING and the run continues; in the shipped tree of this branch xnu-local-build never uses the mirror [obs: `grep -n mirror tools/xnu-local-build` in the offload-xnub worktree finds nothing], so with --network=none stager 0019 dies (AP-262) after 7-11 min. tools/batch-20u3 (93b5af6) contains 2b58306, tools/xnub-mirror and its servable fix [obs: `git branch --contains`, xnu-local-build there has 6 mentions, xnu-src-mirror has `servable`].
- Fix: under `--validate` (and in plain staging too) make the missing tool `err 2 "tools/xnu-src-mirror missing in $here: stage from a checkout that has tools/xnub-mirror (e.g. tools/batch-20u3)"`; also `grep -q xnu-src-mirror "$here/tools/xnu-local-build"` else the same error. Run the first real proof from tools/batch-20u3.

### F5 (LOW) rc 95 + "run the stager" for a mirror tool ERROR

### F7 (INFO/LOW) smaller points
