## checked
`tools/tool-proposals check preflight` (only this proposal and the new tool match); no other tool checks a run's arguments before the lock. Read from source: `shim/out/gate.result` holds the newest `GATE PASS|FAIL <short hash>[+dirty] ...` line (tools/check-all.sh:8-9,93); `flashed-userdata.txt` lines are `<sha256> <date> <img>` (tools/fflash-userdata.sh:13,21); `tools/phone-lock status` exits 0 when free and `check` exits 0 for the caller's token; xrun options are listed in the tools/xrun header (`--args --expect --stop-on --hard-timeout --overlay`), probe-run's in its header (`--expect --timeout --label`).

## why
Each check is one antipattern that already cost hardware cycles: bootargs/syntax (AP-10, a name nobody parses is a lost cycle), reach (AP-27), timeout (AP-14/AP-22, from `tools/runs stats --json`, TP-023), gate (AP-21), root, lock. Boot-arg names come from `tools/bootargs-known.txt`, generated by `tools/run-preflight --gen-bootargs` from the pristine xnu-8796 (`~/pixelios-artifacts/xnu-pristine`, docs/LOCAL-BUILD.md:41) plus `xnu/patches/*.patch` (macro argument positions read from osfmk/kern/startup.h:225-380). A grep is a start, not proof: names parsed outside xnu (observed missing from the kernel tree: wdt_test, ignition_level, launchd_unsecure_cache, all used in the demo2 form) FAIL until they are added with a citation to `tools/bootargs-extra.txt`.

## output
One line per check (`PASS|FAIL|SKIP`), `note:` lines, last line `RESULT: PASS` or `RESULT: FAIL <check>: <reason>`; exit 0 / 1 / 2 (bad arguments). `--json` prints the same as one JSON object. Not implemented, shown as SKIP/note, because no verified source exists yet: image meta vs HEAD (which image xrun boots), `--overlay` only after migration finished, the build's recorded root (only `--root-sha`). The timeout margin (default 60 s) is a guess. Wiring into xrun/probe-run and a gate step for `--gen-bootargs --check` (needs the pristine tree) are separate changes.

## risks
Read-only, host-only; runs `tools/runs`, `tools/phone-lock status|check`, `git rev-parse`. No adb/fastboot. A false FAIL on bootargs is possible for names parsed outside xnu (fix: bootargs-extra.txt with a citation).
