# Coding rules

Each rule: one sentence, bad, good, `check:` (the tool that rejects it), `from:` (review labels, fix commit). A rule marked
review-only counts double against the 30-rule cap; none is review-only below (CR-13 and CR-20 keep a review residue).

## Common

### CR-01 A check must be able to fail
Every assertion, audit and count bound has an input that makes it fail, fails with `raise`/exit 1, and runs in the gate.
    bad:  EXPECT(ev[lo].t == EV_W || ev[lo].t == EV_ISO_CLR || 1);      [ "$polls" -le 3 ]   # 0 polls passes
    bad:  assert kind == "read_only" and not probe, "log is for ..."     # stripped under python -O
    good: EXPECT(ev[lo].t == EV_W || ev[lo].t == EV_ISO_CLR);           [ "$polls" -ge 1 ] && [ "$polls" -le 3 ]
    good: if kind != "read_only" or probe: raise ValueError("log is for ...")
check: new `tools/check-rules.py` R01 rejects `|| 1)`/`|| true)` in EXPECT/assert of `shim/*_host_test.c`, bare `assert` in
`tools/gen_wlan_seq.py`, `tools/boards.py` and `check_*` bodies of `tools/test-bluejay-boot.py`; new `tools/test_selftests_wired.py`
fails when a tool with `--self-test` is in no `tools/check-all.sh` step or `test_*.py`.

### CR-02 Every new refusal, audit clause or check ships a killing mutant, run through one shared runner
A mutant replaces every occurrence, never a fixed register, runs under `python -B`, and a survivor fails unless marked equivalent with the implying clause.
    bad:  s = s.replace("tst\tw4, #0xffff", "tst\tw4, #0xfffe", 1)
    bad:  for m in mutants: open(path, "w").write(m); subprocess.run(["python3", test])
    good: mutate.sub(obj, r"tst\tw(\d+), #0xffff", r"tst\tw\1, #0xfffe")
    good: mutate.case("memw_ok dead-read", equivalent="implied by (coreinfo & 0x3E0) == 0")

a commit adding `return -2`/`raise AssertionError` to `shim/*.c` or `tools/test-bluejay-boot.py` adds a `mutate.case(` in the
same commit, and a `mutants = [` loop outside `tools/mutate.py` fails. Enforces AP-16/26/37 and REVIEW.md "no test that fails before".
